A research prototype that requests a supervisory stop when perception is uncertain.

VAJRA monitors a tabletop human–robot workcell. RGB handles routine detection, and thermal is checked only when the RGB result stays unclear. A deterministic state machine then selects CLEAR, CAUTION, or VETO. If a signal is stale, missing, or persistently ambiguous, the prototype requests a supervisory stop.

Academic support. This work was supported by Prof. Dr. Ing. Matthias Krauledat and Prof. Dr. Ing. Ronny Hartanto.

Prototype boundary. VAJRA is a research prototype, not a certified machine-safety device.

What it does

  • RGB is the default high-rate channel: candidate localisation via YOLO, hand confirmation via MediaPipe landmarks.
  • Thermal is queried only when a bounding box lingers in the ROI without stable landmarks. the linger-box condition.
  • A deterministic state machine converts evidence into CLEAR, CAUTION or VETO using asymmetric entry and exit thresholds, so a single ambiguous frame can't make it flicker.
  • VETO never exits straight to CLEAR. it steps down through CAUTION, because recent ambiguity near a boundary is itself evidence.
  • Any stale or missing signal defaults to VETO. Loss of communication produces a supervisory stop request, by construction.

What I found

Across 58 controlled trials, there were 0 observed unsafe CLEAR decisions. With bare skin or coloured gloves, thermal contrast was useful: it reduced unexpected state transitions by up to 80%, and no missed supervisory stop requests were observed in those conditions.

Insulated black gloves were the useful negative result. Thermal added perception-to-decision latency and oscillation but did not change the observed unsafe CLEAR count, because the insulation removed the surface contrast the sensor needed. In that condition, the combined system behaved like RGB-only. I would not claim a fusion benefit where the second sensor had no useful signal.

This is an experimental result, not evidence of zero residual risk or safety certification.
